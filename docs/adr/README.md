# Architecture Decision Records (ADR)

このディレクトリは、プロジェクトの重要な設計決定を記録・管理するための ADR (Architecture Decision Records) を保存します。

## 目的

- 重要な技術的判断・設計選択を文書化する
- 決定の背景・トレードオフを明確にする
- 新しいメンバーがプロジェクトの設計思想を理解できるようにする
- 意思決定プロセスを透明化する

## ファイル形式と保存

- **形式**: MADR (Markdown Architecture Decision Records) 形式で日本語記述
- **ファイル名**: `NNNN-kebab-case-title.md`（NNNN は4桁ゼロ埋めの通し番号）
- **保存場所**: 本ディレクトリ直下

例: `0001-monorepo-structure.md`

## `adr` スキルでの運用

`adr` スキルで以下の操作ができます：

| 操作           | コマンド                           | 説明                                                    |
| -------------- | ---------------------------------- | ------------------------------------------------------- |
| 新規作成       | `adr new [タイトル]`               | 新しい ADR を自動作成（ファイル名・ステータス自動設定） |
| 一覧表示       | `adr list`                         | 全 ADR の一覧を表示                                     |
| 個別表示       | `adr [番号]`                       | 指定した ADR の内容を表示                               |
| ステータス更新 | `adr status <番号> <新ステータス>` | ADR のステータスを変更                                  |

## ステータス

ADR のステータスは以下のいずれかです：

- `提案中` - 検討中のため、まだ承認されていない状態
- `承認済み` - チームにより承認された決定
- `廃止済み` - 有効でなくなった決定
- `差し替え済み` - より新しい ADR に置き換わった決定
