# 実装計画書ディレクトリ

このディレクトリは、LLMエージェントによるプロジェクト実装の計画・管理を目的としています。

## ディレクトリ構成

- `NNNN-kebab-case-title.md`: 実装計画書（番号は4桁ゼロ埋め、日本語で記述）
- `NNNN-tasks/N-M.md`: 計画を分解したタスク仕様書

## 計画書の読み方

各計画書には以下の情報が含まれます：

- **目的と背景**: ADRの決定事項や課題の整理
- **タスク一覧**: `N-M` 形式で、`N` は群、`M` はタスク番号
- **各タスク**: 「変更ファイル」（変更対象を glob で指定。読み取り専用は注記）と「依存」（依存タスク ID）を明記

## スキルの使い方

### `plan` スキル

ADRや設計決定から計画を新規作成し、実装可能なタスクに分解します。
実装計画書を `docs/plans/NNNN-kebab-case-title.md` として生成します。

### `next` スキル

計画書の先頭から最初の未完了タスクを1つ取り出し、`implementer`エージェントで実装します。
逐次実装により、発見された新しい課題に対応できます。

### `fanout` スキル

依存が解決済み**かつ**変更ファイルが重ならない複数タスクを、
`implementer`/`reviewer` サブエージェントで並列実行・レビュー・自動マージします。
実装速度を大幅に高速化できます。

---

各タスクの「変更ファイル」と「依存」は、並列実行可否の判定に使用されます。
