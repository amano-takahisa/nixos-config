## 関連ADRの決定事項（要約）

- ADR (Architecture Decision Records) は MADR形式・日本語で `docs/adr/` に
  `NNNN-kebab-case-title.md`（番号は4桁ゼロ埋め）として保存する
- `adr` スキルで新規作成（`new [タイトル]`）・一覧表示（`list`）・個別表示
  （番号指定）・ステータス更新（`status <番号> <新ステータス>`）ができる
- ステータスは `提案中` / `承認済み` / `廃止済み` / `差し替え済み` のいずれか
